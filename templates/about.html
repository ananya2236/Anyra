About Anyra

Anyra is your AI-powered voice companion — engaging, smart, and interactive. She listens, understands, and responds with personality, powered by cutting-edge AI.

✨ Core Features

🎙️ Live Voice Capture

Manual & automatic recording modes for seamless interaction.

🧠 Smart AI Responses

Context-aware replies powered by Google Gemini 1.5 Flash.

🗣️ Natural Voice Output

Murf AI TTS plus browser fallback for lifelike speech.

👁️ Animated Avatar

Eye-tracking visuals and glowing orb animation bring her to life.

♻️ Persistent Context

Remembers conversations with session-based memory.

🎭 Custom Personas

Switch between personalities like pirate, professor, or futuristic AI.

🚀 How to Use Anyra

1️⃣ Open the Web App

Navigate to Anyra in your browser to get started.

2️⃣ Click Start

Press the Start button to initialize the assistant.

3️⃣ Enter Required API Keys

- Murf API Key: Enables natural voice output.
- AssemblyAI API Key: Enables real-time speech-to-text.
- Google Gemini API Key: Powers context-aware AI responses.

4️⃣ Save API Keys

Click Save to store your keys so Anyra can use them during your session.

5️⃣ Start Interacting

Press Start (if not already active) and begin talking or typing to Anyra. Switch personas or try her skills like weather, news, or jokes.

6️⃣ Optional Features

Upload audio recordings or switch between avatar and chat UI for a richer experience.
